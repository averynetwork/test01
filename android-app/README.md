# Brarchive для Android

Минимальное Android-приложение на Kotlin/Jetpack Compose для выбора файла, выбора папки назначения и запуска Go-движка Brarchive. Движок собирается для Android arm64 в GitHub Actions и включается в APK как asset.

Сборка: из корня репозитория запустите workflow **Build Brarchive Android APK**. APK появится в артефактах успешного запуска.
